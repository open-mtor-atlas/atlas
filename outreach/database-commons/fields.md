# Database Commons submission: Oliver's mTOR Atlas

## 1. Basic information

- **Database name:** Oliver's mTOR Atlas
- **Short name/acronym:** mTOR Atlas
- **URL:** https://mtor-atlas.org/
- **Description:** An evidence-graded, open-access database of 354
  curated primary research studies on mTOR (mechanistic target of
  rapamycin) signaling. Each study is linked to an evidence tier
  (A = systematic review/meta-analysis through D = mechanistic/
  in-vitro), extracted findings, and the pathway entities/processes it
  involves (146 curated entities), forming a browsable knowledge graph
  of mTOR biology.
- **Organism/species scope:** Cross-species (human and model-organism
  studies, tagged per record)
- **Data type:** Literature-curated biomedical knowledge base /
  pathway-evidence database
- **Institution/affiliation:** Independent research project (Oliver
  Barton, Prague)

## 2. Data

- **Data source:** Manually curated from primary literature indexed in
  PubMed (310 of 354 records have a mapped PMID); each record's
  evidence tier, finding, and pathway associations are hand-extracted
  and reviewed, not automatically generated.
- **Data scale:** 354 studies, 146 pathway entities/processes
- **Update frequency:** Ongoing (rolling additions and corrections;
  see public changelog: https://mtor-atlas.org/changelog/)
- **Data format(s) available for download:** CSV and JSON exports
  (https://mtor-atlas.org/data/exports/), full corpus described at
  https://mtor-atlas.org/data/

## 3. Access

- **Access type:** Free, open, no registration or login required
- **License:** CC BY 4.0
- **API availability:** No programmatic API at present; static CSV/JSON
  exports are the machine-readable access path (see section 2)

## 4. Publication

- **Citable DOI:** 10.5281/zenodo.22059963 (Zenodo, permanently
  versioned)
- **Associated publication:** none yet indexed in PubMed (a preprint
  manuscript is in preparation -- see Ukol 9 in this same outreach
  round); cite via the Zenodo DOI above in the meantime.
- **Contact:** Oliver Barton (ORCID:
  [0009-0008-2025-2148](https://orcid.org/0009-0008-2025-2148))
- **Also registered with:** FAIRsharing (ID 8905), bio.tools (ID
  `olivers_mtor_atlas`)
